# 飞机场独立评测准则与方法学规范

为确保全站评测内容与网络性能测试报告的客观性、可信度与科学性，飞机场编辑部制定并严格遵守以下**五大评测核心规范**。

---

## 一、网络测速与晚高峰采样规范

普通非高峰时段的测速数据缺乏实际参考意义。飞机场所有收录的服务商均必须通过严格的**极限工况压力测试**：

1. **测试时间窗口**：
   - **黄金测试窗口（晚高峰）**：每日 20:00 至 23:30（公网国际出口拥堵峰值时段），单节点至少执行 3 次独立并发测速取中位数。
   - **平峰基准窗口**：每日 14:00 至 16:00，用于测定机房的底层硬件极限带宽能力。
2. **测试维度与指标权值**：
   - **丢包率（Packet Loss，权重 40%）**：以 100 次 ICMP/TCP ping 测试为基础，晚高峰丢包率超过 5% 的节点将被判定为降级；专线（IEPL/IPLC）节点丢包率需保持在 0.5% 以下。
   - **网络抖动与往返时延（Jitter / Latency，权重 20%）**：关注往返延迟的标准差，抖动持续低于 15ms 的线路视为高稳定性。
   - **单线程与多线程下载速率（Speed Throughput，权重 25%）**：分别测试单 TCP 流速度（模拟网页秒开与长连接）与多流速度（模拟 4K/8K 视频加载）。
   - **初次连接建立耗时（Time To First Byte / Handshake，权重 15%）**：评估 TLS 握手及代理协议的解析效率。

## 二、真实性与专线真伪鉴定流程

针对业内部分低端机场使用廉价公网直连冒充高价专线的乱象，我们执行三道硬性核验程序：

- **链路路由追踪（MTR / Traceroute）**：检查出境数据包是否在边境机房内网端口处汇聚，直连跳数与内网私有网段（10.x.x.x）是否存在，排除伪造伪专线。
- **公网波动对照测试**：在特殊网络敏感时期或公网海底光缆割接维护期间，观察该节点的丢包曲线是否与公网出口波动同步发生断崖式下跌。
- **协议握手特征嗅探**：通过抓包分析协议头部填充字节与 TLS 指纹混淆效果，验证其抗封锁与防 DPI 识别能力。

## 三、AI 工具与跨国流媒体解锁判定

所有标注“支持 ChatGPT”或“流媒体解锁”的节点，必须每日通过自动化脚本执行双向测试：

1. **OpenAI / Claude 严格风控测试**：通过向目标 API 提交握手请求，检测 HTTP 响应码。若返回 `403 Forbidden`、`Access Denied` 或触发 Cloudflare 验证盾，该节点将被标记为“解锁失效/脏 IP”。
2. **原生住宅 IP 与机房广播 IP 区分**：查询 IP 归属数据库（IP2Location、MaxMind、IPinfo），明确标注该节点属于商业机房（Data Center）还是原生 ISP 宽带（Residential）。
3. **Netflix / Disney+ 流媒体分级测试**：区分“仅解锁非版权自制剧”与“全量原生地理解锁”。
