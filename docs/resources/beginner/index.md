## 章节一 零基础科学上网技术全貌与新手五步极速上手指南

很多新手第一次尝试跨境访问时，容易被网络教程中充斥的各种软件名与协议代号搞得晕头转向。事实上，只要理解了整个代理链路的数据流向，就能彻底摆脱迷茫。

### 1.1 科学上网的基础工作原理剖析

普通的上网行为好比你在国内投寄一封平信：信封上写着目标服务器的真实地址（例如某个海外知名技术站点）。当这封信件经过运营商的国际出口路由器时，公网防火墙（GFW）会对信封上的域名地址及数据特征进行自动化检测。一旦识别出该目标被列入管控清单，信件就会在边境出口被直接拦截并丢弃，导致你的浏览器弹窗提示“连接已超时”。

而通过“客户端 + 机场节点”进行科学上网，则相当于你在本地聘请了一位专属的保密翻译官（**本地客户端**）和一条专有绿色邮路（**机场专线服务器**）：
1. **本地打包与端对端加密**：当你想访问海外站点时，本地客户端在你的电脑或手机内部瞬间建立一个本地代理监听端口（例如 `127.0.0.1:7890`）。浏览器将请求发送给客户端后，客户端利用高强度加密算法（如 AES-256-GCM 或 ChaCha20-Poly1305）将数据包裹封装，使其在外部网络看来只是一串毫无意义的杂乱随机字符。
2. **直通中转中转站**：加密后的包裹直接发送给位于境内安全机房的机场入口服务器，或者通过专线光缆直接送往海外。由于数据全程处于高强度密文状态且通信目标并非敏感海外网站，公网审查系统根本无法识别其内部真实意图，直接予以放行。
3. **海外节点解密并代理访问**：当包裹抵达机场部署在香港、日本或美国的境外出口节点时，出口服务器负责将密文还原成原始网页请求，并以该服务器自身的海外本地原生 IP 向目标站点发起正常访问，最后将获取到的网页数据再次加密回传给你的客户端。整个过程在数毫秒内完成，你在屏幕前感受到的就是网页瞬间顺畅秒开。

### 1.2 新手从零到顺畅上网的标准五步闭环

遵循以下标准五步法，即便没有任何计算机网络知识的新手，也能在 5 到 10 分钟内完成全流程配置：

#### 第一步 获取正规可靠的开源客户端软件
绝对不要通过百度搜索、贴吧网盘分享或不知名破解论坛下载所谓的“全家桶汉化修改版”。无数案例表明，第三方二次打包的客户端往往被恶意植入了静默挖矿程序或广告推广脚本。
- **Windows 与 macOS 电脑用户**：直接前往 GitHub 官方开源仓库下载当前主流的 `Clash Verge Rev`（选择以 `.msi` 或 `.dmg` 结尾的正式发行版安装包）。
- **安卓手机用户**：下载官方原版开源的 `Clash Meta for Android` 或 `sing-box` 安装包。
- **苹果 iOS 用户**：准备一个海外非国区 Apple ID（如美区），登录 App Store 购买下载正版 `Shadowrocket`（俗称小火箭）。

#### 第二步 挑选并订阅一家支持小额月付的合规机场
访问口碑良好的老牌专线机场官网（如光速云或二毛机场），注册账号并进入套餐购买页面：
- **新手第一原则（只买月付）**：无论商家给出的年付或两年付折扣多么诱人（例如买一年送半年），新手的第一笔订单必须坚决选择单月支付。花费十几元进行真实晚高峰测速，确认在你家里的本地宽带环境下能够稳定运行后，未来再考虑季度续约。
- **付款后进入用户控制台**：支付成功后，在机场后台的“仪表盘”或“订阅中心”中，找到你的专属服务区域。

#### 第三步 一键导入或复制订阅 URL 到客户端
在机场后台通常会看到两种导入方式：
- **一键导入（推荐小白）**：点击“一键导入 Clash”按钮，浏览器会自动唤醒你刚才安装好的客户端，并自动完成链接填入与初次拉取。
- **手动复制订阅链接**：如果浏览器未弹出跳转提示，点击“复制订阅地址”按钮。随后手动打开客户端，进入左侧的“订阅（Profiles）”面板，将刚才复制的完整长链接粘贴到输入框中，点击右侧的“下载/导入（Download）”。待进度条走完，你就会看到节点配置文件已经成功加载。

#### 第四步 启动系统代理与确认规则分流模式
很多新手导入配置后就以为完工了，结果发现网页依然无法打开。这是因为本地网络流量尚未正式接驳到客户端中：
- 在客户端的主界面或控制面板中，找到 **“系统代理（System Proxy）”** 开关并将其点击打开。此时电脑右下角的网络设置会自动将本地流量路由重定向至客户端监听端口。
- 检查分流模式开关：客户端通常提供“规则（Rule）”、“全局（Global）”和“直连（Direct）”三个选项。**新手务必确保其勾选在“规则（Rule）”模式下**。在该模式下，访问国内的百度、微信、网易云音乐等国内服务完全走你自家的原生宽带，不耗费机场套餐流量，只有访问海外被限制的网站时才会自动走代理。

#### 第五步 展开节点列表进行延迟测速并选定接入点
进入客户端的“代理（Proxies）”界面：
- 点击面板右上角的“WiFi 无线电波”图标或“测速”按钮。客户端会在一秒钟内向海外健康服务器并发发送测试包，并在各个节点卡片右下角标明真实的往返延迟数值（例如 `45ms`、`89ms`）。
- **节点选择原则**：绿色数字（通常低于 100ms）代表当前网络极佳的节点，优先点击选中香港（HK）或台湾（TW）节点，因其物理距离离大陆最近，网页秒开响应最快；如果需要使用某些特定海外 AI 服务（如 Claude 或某些流媒体），则在列表中点击选中美国（US）或新加坡（SG）对应专属节点。此时打开浏览器，输入常见海外学术站点，即可享受畅通无阻的极速体验。

### 1.3 首次导入配置后的三大必要自检操作

完成上述五步后，在正式展开工作前，推荐花一分钟完成三项简单自检，防患于未然：
1. **测试国内网站连通性**：打开浏览器访问新浪网或百度首页，确认能否瞬间加载且网页顶部未提示异地登录。这证明“规则分流”机制运行完全正常，国内流量没有被误路由。
2. **检查公网 IP 地理定位**：打开专门的 IP 监测网页（如 `ip138.com` 与 `whoer.net`），在 `ip138.com` 上应该显示你本地城市的电信或联通宽带 IP；而在 `whoer.net` 上则应该显示为你刚才在客户端选中的香港或美国机房 IP。这一步能够彻底确实验证内外网流量完全按预期精准分流。
3. **客户端开机自启动与静默运行配置**：在客户端的全局设置中，勾选“开机自动启动（Start with Windows/macOS）”以及“启动时最小化到系统托盘”。这样每天开启电脑时软件会自动在后台静默运行，无需每天手动翻找图标拉起服务。

## 章节二 机场核心技术黑话大白话解析与参数避坑

新手在查看机场宣传单或进阶技术交流群时，往往会被诸如“IEPL”、“BGP”、“倍率”、“落地机”等专业术语搞得一头雾水。理解这些黑话的真实含义，是避免被黑心商家忽悠的照妖镜。

### 2.1 物理线路架构解析（IEPL 与 IPLC 专线 vs BGP 中转 vs 直连）

决定一家机场网络质量好坏与价格高低的根本核心，在于其在海关边境处所租用的**物理线路通道类型**：

| 线路术语 | 全称与技术实质 | 物理传输通道原理 | 晚高峰抗封锁表现 | 商业成本与适合人群 |
| :--- | :--- | :--- | :--- | :--- |
| **IEPL 内网专线** | 国际以太网私有专线 (International Ethernet Private Line) | 境内机房与境外机房之间拉设端对端物理光纤，网络完全走跨国内部私网传输，根本不经过国际公网海关防火墙。 | 极其恐怖的稳定性，哪怕遭遇公网大规模封锁阻断，专线依然保持 0 丢包。 | 线路租金极其昂贵，适合追求极致稳定性的外贸办公、远程工作与专业投资交易者。 |
| **IPLC 国际专线** | 国际私有租用线路 (International Private Leased Circuit) | 与 IEPL 类似的点对点硬线连接，属于点对点数据通信专线，同样不经过公网 GFW 过滤审查。 | 稳定性与抗封锁能力与 IEPL 基本持平，几乎感知不到晚高峰公网网络拥堵。 | 专线硬件成本高，是高品质商业机场的主力旗舰线路支撑。 |
| **BGP 多线智能中转** | 边界网关协议公网中转 (Border Gateway Protocol) | 在境内各大核心城市（如上海、深圳、广州）部署拥有电信、联通、移动多线接入的机房服务器，用户先连接至国内机房，再由该机房通过公网大带宽隧道将流量转发至境外。 | 表现优于普通直连，但在公网国际出口严重拥堵或特殊网络敏感时期，公网隧道可能出现波动丢包。 | 性价比极高，流量单价远低于专线，是中档大众高性价比机场的标准配置。 |
| **公网直连 (普通直连)** | 国际公网路由直接连接 (Direct Connection) | 客户端直接与位于境外的 VPS 服务器通过普通公网建立连接，跨越数千公里的国际海底公网光缆直连。 | 极度脆弱，晚高峰 20:00 至 23:00 期间由于国际出口严重拥塞，丢包率往往超过 30%，视频频繁卡顿甚至频繁断联。 | 成本极其低廉，多见于几元钱的廉价跑路机场或公共免费节点。 |

### 2.2 节点倍率机制的秘密与隐藏扣费陷阱

在节点的命名后缀中，经常能看到诸如 `[1.0x]`、`[0.1x]`、`[3.0x]` 等字样。所谓的**倍率（Multiplier）**，就是机场服务器统计你消耗流量的放大比例系数：
- **基准倍率（1.0x）**：当你使用 1.0 倍率的节点下载了 1GB 的文件时，你的账户配额中就会实扣 1GB 流量。这是行业中最标准的计费方式。
- **低倍率福利节点（如 0.1x / 0.2x）**：使用 0.1 倍率的节点下载 1GB 文件，系统只会从你账户中扣除 0.1GB（即 100MB）流量。这种节点通常部署在普通公网直连线路上，速度相对较慢或延迟偏高，但非常适合用来通宵挂机下载大型游戏安装包或离线同步海量资料。
- **高倍率昂贵专线节点（如 2.0x / 3.0x 甚至 5.0x）**：使用 3.0 倍率的节点下载 1GB 文件，你的账户会被瞬间扣掉 3GB 流量。这类节点通常配置了成本极高的极速企业级专线，或者配备了昂贵的海外高风控纯净住宅 IP。新手必须看清倍率标识，切忌在 5.0 倍率的高清专线节点上挂机下载大容量蓝光电影，否则数百吉比特的月度流量可能在几个小时内被彻底消耗干净。

### 2.3 协议选型演进史（从 Shadowsocks 到 VMess 与 Trojan、VLESS）

随着公网流量识别技术的不断迭代演进，客户端与机场之间的通信协议也经历了几轮代际更替：
1. **第一代基石 Shadowsocks（SS 协议）**：最老牌轻量的对称加密代理协议。由于协议本身头部特征简单，虽然在跨越公网直连时容易被深度数据包检测（DPI）通过机器学习模型精准识别，但在 **IEPL 与 IPLC 纯内网专线** 环境下，由于传输过程完全不经过公网海关审查，Shadowsocks 凭借极低的处理延迟与近乎零的 CPU 运算损耗，至今依然是高端专线机场首选的最佳低延迟协议。
2. **第二代抗封锁中坚 VMess 与 Trojan**：
   - **VMess**：伴随 V2Ray 诞生的复杂混淆协议，支持动态时间戳与复杂请求头，抗审查能力强，但配置繁杂且存在微量握手损耗。
   - **Trojan**：模仿真实互联网 HTTPS 流量的典范。它将所有代理数据完整包装为标准合规的 TLS 1.3 证书加密数据，外部防火墙在审查时只能看到正常的 443 端口网页访问，具备极高的隐蔽性与稳定性。
3. **第三代现代前沿 VLESS 与 Hysteria 2**：
   - **VLESS（搭配 Reality 架构）**：彻底剔除了多余的加密握手负载，通过借用真实大型海外商业网站的合规 TLS 证书完成身份伪装，达到了速度与抗封锁的完美平衡。
   - **Hysteria 2（歇斯底里 2）**：基于 UDP 协议改造的超高速魔改协议。专为恶劣、高丢包、严重限速的弱网环境而生。即便在公网国际出口丢包率高达 30% 的极端恶劣工况下，Hysteria 2 依然能通过强行多发冗余包的方式榨干本地带宽跑满 4K 视频，是当前直连网络中表现最出色的技术黑马。

## 章节三 全主流操作系统客户端选型避坑与正规渠道获取

选对一款干净、稳定且符合直觉的客户端软件，能省去日后 80% 的莫名排障时间。以下针对四大主流操作系统提供经实验室实测的最佳选型路线：

### 3.1 Windows 平台首选客户端与防误报运行规范

在 Windows 10 与 Windows 11 环境下，**Clash Verge Rev** 是目前综合体验最佳的桌面客户端：
- **正规获取通道**：务必认准 GitHub 官方开源仓库 `clash-verge-rev/clash-verge-rev`。在 Release 界面下载对应的安装程序（64 位系统选择 `Clash.Verge_x.x.x_x64-setup.exe` 或便携免安装版 `x64_portable.zip`）。
- **Windows Defender 误报消除**：由于代理软件内部集成了网络驱动拦截（TUN 虚拟网卡驱动）和跨进程端口劫持功能，微软自带的 Windows Defender 或第三方安全卫士（如 360）偶尔会将其核心二进制文件误报为“潜在不受欢迎程序”。遇到此情况，切勿慌张删除，在安全软件的弹窗中选择“允许在设备上保留”，或在防护中心中将该软件的安装目录整体添加为“扫描排除项（Exclusion）”。

### 3.2 macOS 平台双架构适配与权限授予要点

macOS 系统以安全机制严苛著称，新手在安装与初次启动时需要注意以下细节：
- **Apple Silicon 芯片与 Intel 架构选择**：下载时注意辨别安装包后缀。如果你的 Mac 使用的是苹果自研的 M 系列芯片（M1/M2/M3/M4），必须下载带有 `aarch64` 或 `arm64` 标识的 `.dmg` 文件；如果是较老的 Intel 处理器机型，则下载带有 `x64` 标识的版本。下载对应架构的原生版本能让客户端功耗大幅降低，整天挂机也不会导致笔记本发热耗电。
- **首次运行提示“已损坏，无法打开”解决秘籍**：由于 macOS Gatekeeper 安全门禁对未经苹果官方付费公证的开源软件会默认拦截，在将软件拖入“应用程序”文件夹后双击运行时，系统可能弹窗提示“应用已损坏，应将其移到废纸篓”。此时无需重新下载，打开 Mac 自带的“终端（Terminal）”，输入以下一行授权指令并按下回车，输入电脑开机密码即可永久解除限制：
  ```bash
  sudo xattr -r -d com.apple.quarantine /Applications/Clash\ Verge.app
  ```
- **核心辅助工具与系统权限授权**：在初次开启“TUN 模式”或“系统代理”时，macOS 会弹出系统对话框要求输入管理员密码以安装专用的系统网络辅助工具（Privileged Helper Tool）。点击“允许”并输入密码，系统才能赋予软件修改本地系统网络路由表的底层特权。

### 3.3 Android 平台电池优化与后台保活设置

安卓系统的碎片化和各大手机厂商（华为、小米、OPPO、vivo）激进的省电机制，是导致手机端代理经常频繁断联的元凶：
- **首选客户端推荐**：首选开源的 **Clash Meta for Android**（简称 CMFA）或 **sing-box for Android**。
- **必须解除的系统电池优化锁**：进入手机的“设置” -> “应用管理” -> 找到你的代理客户端，将“电池管理/耗电策略”由系统默认的“智能省电”或“优化”手动修改为 **“无限制”或“允许后台高耗电运行”**。各大国产定制系统在熄屏后为了节省电量，会在几分钟内强行杀死未处于白名单中的网络连接守护进程。
- **任务栏加锁与自启动授权**：划出手机的多任务后台界面，在代理软件的任务卡片上向下拉动或长按，点击出现的“小锁头”图标将应用在后台加锁锁定。同时在“应用自启动管理”中，将“允许后台自启动”与“允许关联启动”开关全部开启。完成这三步后，手机即便在深夜熄屏待机，早晨醒来也能持续保持推送通知不断联。

### 3.4 iOS 平台外区 Apple ID 准备与 Shadowrocket 安装避坑

苹果 iOS 系统的封闭生态决定了代理软件的下载流程稍显特殊：
- **国区 App Store 的客观限制**：由于国内应用商店合规审查要求，所有与科学上网相关的网络代理工具（如 Shadowrocket、Quantumult X、Loon、Stash）均已从中国大陆区 App Store 下架。在国区商店中搜索“小火箭”，搜出来的全部是名称相似的钓鱼广告软件或山寨清理工具，切勿上当付费。
- **获取外区（美区/港区）Apple ID 的规范路径**：
  1. 可以在苹果官网利用任意未经注册的海外邮箱自行注册一个全新的美区 Apple ID（账单地址可利用海外地图随意填写一个免税州如俄勒冈州的真实商业地址）；
  2. 也可以在可靠的数字电商平台购买一个现成的独享外区账号。
  3. **至关重要的安全红线**：获取外区账号后，**绝对不要在手机系统的“设置”最顶层登录该账号（切勿绑定 iCloud）**！这可能导致你的手机被恶意远程锁机勒索。**唯一正确的操作是仅在 App Store 应用商店内部退出当前账号并登录外区账号**。
- **Shadowrocket 购买与安装**：在 App Store 登录外区账号后，搜索 `Shadowrocket`（官方正版图标为一个白色的四翼火箭在黄色背景之上，开发者标明为 Pan Gu）。该软件在外区售价通常为 2.99 美元，购买正版后终身免费更新，下载完毕后即可在 App Store 退出外区账号换回你原本的国内主账号，软件日常使用与更新完全不受影响。

## 章节四 客户端分流模式深度剖析与规则集调度实践

代理客户端最强大、最核心的灵魂功能在于其具备精密的**网络流量分流调度大脑**。搞清不同的运行模式，是实现“内外网无缝丝滑切换”的关键。

### 4.1 规则模式（Rule）的工作原理与国内流量直连保障

绝大多数资深玩家在 99% 的日常使用场景中，都会将客户端固定锁定在 **“规则模式（Rule）”**：
- **路由匹配决策树机制**：当你的电脑向外部网络发起一个请求时，客户端会按照内置的路由规则清单（Rule Providers）自顶向下逐行进行比对。
- **智能国内白名单放行**：规则库中预先内置了上万条中国大陆顶级域名（如 `.cn`）与主流国内互联网服务列表（如腾讯、阿里巴巴、百度、字节跳动、美团），以及大陆官方广播的全部公网 IPv4/IPv6 地址段（GeoIP CN）。一旦匹配到请求属于国内资源，客户端会在底层直接指引该数据包走你本地的家庭宽带物理网卡直连发出，**完全不经过外部代理服务器**。
- **精准跨国路由导流**：如果匹配到目标属于海外服务（如 Google、YouTube、GitHub、Wikipedia），或者属于未被收录的境外未知 IP 时，客户端才会将流量送入你指定的代理节点进行隧道中转。这保障了你在刷国内淘宝、打国服英雄联盟的同时，浏览器另一侧窗口依然能以超高速度流畅播放 YouTube 4K 视频，彼此完全互不干扰。

### 4.2 全局模式（Global）与直连模式（Direct）的适用场景与风险

除了日常的规则模式外，客户端通常还保留了“全局”与“直连”两种特殊工作模式：

1. **全局模式（Global）**：
   - **工作机制**：彻底无视任何内置的智能分流规则列表。电脑产生的所有向外发送的网络数据包（包括访问百度、微信聊天、甚至是系统局域网打印机通信），都会被无条件强制打包并全部通过你选中的代理节点发送出去。
   - **典型适用场景**：某个新出现的极其冷门的国外科研数据库未被主流开源规则库收录，在规则模式下被误判为了国内直连导致打不开；或者需要对某个跨国应用程序进行完整的外网环境沙箱模拟排错。
   - **日常开启的严重负面后果**：如果你长时间忘记关闭全局模式，访问国内所有网站都会经由海外节点绕行大半个地球再折返回来，造成严重的网络延迟暴增；更严重的是，你的国内银行 App、微信和支付宝会频繁检测到异地登录报警，并判定你的账户存在被盗风险从而触发风控冻结。
2. **直连模式（Direct）**：
   - **工作机制**：相当于将客户端的转发功能临时挂空挡。所有网络流量一律走本地原生网卡直接对外发起连接，完全不调用任何代理节点。
   - **典型适用场景**：当你在进行国内超大文件极速下载（如百度网盘或迅雷高速下片），或者打国内对延迟极其苛刻的竞技网游时，切换为直连模式可以释放客户端对数据包的一切中间检查，将整机性能完全交由硬件网卡发挥。

### 4.3 为什么开启代理后访问国内网站变慢或提示异地登录

很多新手在开启代理软件后，常有以下困惑：“为什么我开了软件之后，看国外的油管飞快，但打开爱奇艺看国内电视剧却一直在转圈卡顿，或者网易云音乐很多歌突然提示因为版权受限无法播放？”

## 章节六 新手常见联网故障排障自愈完全手册

在日常使用过程中，几乎每位新手都会遇到诸如“节点全红”、“能上微信但打不开网页”、“软件关掉后彻底断网”等经典故障。遇到问题无需慌乱，对照以下手册可在三分钟内快速自愈。

### 6.1 故障一 节点列表全部显示超时或红色 Timeout

**现场症状**：打开客户端点击测速，原本绿色的几百毫秒延迟瞬间全部变成了醒目的红色 `Timeout`，无法连接任何海外网页。

**排障三步自愈法**：
1. **第一步 检查本地宽带是否正常联网**：先在浏览器中尝试打开国内的百度或腾讯网。如果连国内网页也完全打不开，说明是你家里的光猫断网或路由器死机，拔掉路由器电源等待 30 秒重新插上即可。
2. **第二步 校准操作系统的本地系统时间**：这是新手最容易忽视的致命盲区！现代代理协议（如 VMess/Trojan/VLESS）为了防止重放攻击，底层强制要求客户端系统时间与全球真实的国际原子时（NTP）误差不能超过 60 秒。如果你的电脑长期未联网导致本地时钟快了数分钟或慢了数天，底层握手校验会直接全部失败并表现为全面超时。在 Windows 设置中搜索“日期和时间”，点击“立即同步”按钮，同步成功后再点击测速往往能奇迹般瞬间恢复全绿。
3. **第三步 更新订阅配置**：有时候是机场机房临时进行了 IP 割接更换，旧节点的服务器 IP 已经失效。在客户端的“订阅”面板右键点击你的订阅，选择“刷新/更新订阅（Refresh Profile）”，将机房最新的节点同步下来即可排除。

### 6.2 故障二 节点测速正常但所有网页均打不开（DNS 污染与系统代理丢失）

**现场症状**：客户端代理列表里的节点全部测速正常（延迟几十毫秒），但浏览器输入任何国外网址都提示“未连接到互联网”或“找不到服务器 IP 地址”。

**排障自愈法**：
- **检查“系统代理”总开关**：确认客户端主界面的“系统代理（System Proxy）”开关是否处于开启状态。有时候用户在使用第三方清理软件清理电脑垃圾时，会误将 Windows 注册表中的代理端口设置重置抹除。此时手动将客户端内的系统代理开关关闭一次，再重新打开一次，即可强制刷新操作系统的代理注册表。
- **清除本地 DNS 缓存**：在 Windows 任务栏搜索框中输入 `cmd`，右键选择“以管理员身份运行”，在黑色命令行窗口中输入以下指令并按回车：
  ```cmd
  ipconfig /flushdns
  ```
  看到提示“已成功刷新 DNS 解析缓存”后，重启浏览器尝试访问。

### 6.3 故障三 局域网其他软件打不开或邮件客户端无法收发（TUN 虚拟网卡实战）

**现场症状**：在浏览器里看网页完全正常，但电脑上的某些特定桌面软件（例如 Outlook 邮件客户端、Steam 游戏平台、或者在终端命令行里运行 `git clone` / `npm install`）却频繁提示连接失败报错。

**技术根源剖析**：普通的“系统代理”仅对严格遵守操作系统的标准 HTTP/HTTPS 代理环境协议的软件（如 Chrome、Edge 等浏览器）有效。而很多专有桌面软件、大型网络游戏或底层控制台命令行工具，会绕过系统的 HTTP 代理设置，强行使用底层的 TCP/UDP Socket 直接对外发起直连，导致这些软件的流量完全脱离了客户端的管控。

**一键自愈秘籍（开启 TUN 虚拟网卡模式）**：
- 在 Clash Verge Rev 或各大现代客户端的设置面板中，找到 **“TUN 模式（TUN Mode）”** 开关。
- 首次开启时，客户端会自动在操作系统内部安装一张专用的虚拟网络适配器驱动程序。
- 开启 TUN 模式后，客户端会直接在操作系统的网络底层（第三层网络层）接管整台设备产生的所有数据包。无论是游戏客户端、命令行工具还是各种专业办公通信软件，无需进行任何繁琐的单独端口设置，其所有流量都会被系统级强制无感导入代理通道，彻底解决非浏览器软件无法出海的顽疾。

### 6.4 故障四 杀毒软件误杀客户端核心与端口占用冲突处置

**现场症状**：双击客户端图标没有任何反应，或者启动后界面右下角频繁弹窗报错 `Port 7890 already in use`（端口已被占用）。

**排障自愈法**：
- **端口冲突自愈**：当电脑中曾经打开过其他代理工具（例如同时开着旧版 Clash 和 v2rayN），或者某些国内下载软件常驻后台占用了 `7890` 端口时，客户端内核在启动时就会因为端口冲突而闪退崩溃。在 Clash Verge 设置中找到“混合端口（Mixed Port）”，将其由默认的 `7890` 手动修改为一个不常见的随机大端口（例如 `17890` 或 `27890`），保存后重新启动内核即可完美避开端口冲突。
- **杀毒软件白名单信任**：检查 Windows 安全中心是否将客户端核心进程（如 `mihomo.exe` 或 `clash-core.exe`）放进了隔离区。如果被误杀隔离，在防护历史记录中点击“还原”，并将整个客户端安装根目录添加进防护白名单排除项中。

## 12道 新手科学上网高频疑难解答 FAQ

### 1. 新手应该怎么理解“机场”、“梯子”、“节点”和“客户端”的关系？
可以用日常乘坐高铁出行作通俗比喻：“客户端”就是你乘坐的高铁列车（负责承载你平稳前行）；“机场”就是铁路运营公司（负责铺设铁轨与维护服务器机房）；“节点”就是高铁线路上通往不同城市的站点（如香港站、美国站、日本站）；而“梯子”则是民间对这整套翻墙工具组合的一种形象口头俗称。只有列车（客户端）开上正规的轨道（节点），你才能顺利抵达大洋彼岸的互联网目的地。

### 2. 为什么在手机上可以打开油管，但电脑上却怎么也打不开？
由于手机端和电脑端是两台完全独立的物理硬件设备，它们各自的网络设置互不相通。绝大部分新手初次配置时，往往以为在手机上开启了代理，身边的电脑就能自动借光联网。这是错误的认知。要让电脑也能顺畅访问，必须在电脑上单独下载对应的电脑端客户端（如 Clash Verge），并将你在机场后台获取的订阅链接重新导入到电脑端软件中，点击开启系统代理并进行测速后，电脑才能独立获得出海能力。

### 3. 为什么很多老手反复警告“千万不要买年付套餐”？
跨境代理服务行业具有高度的外部不确定性。许多缺乏长期技术运营经验的新机场，在刚开业时为了快速回笼资金，会以极低价格甚至半价优惠吸引新手购买长周期年付或两年付套餐。这类小平台一旦遭遇机房公网防火墙严厉封锁、上游专线成本上涨或资金链断裂，经常会连夜关停服务器并在技术群内彻底失联跑路。购买月付虽然在单价上看似略微贵几元钱，但能让你牢牢握住选择的主动权。一旦发现该商家近期线路频繁卡顿或售后敷衍，下个月可随时拍拍屁股换另一家，将试错损失锁死在十几元以内。

### 4. 节点列表里的“香港 01 [0.5x]”和“日本 02 [3.0x]”里的倍率是什么意思？
倍率是机场计费程序扣减你套餐流量的乘数系数。如果节点标有 `0.5x`，意味着你在该节点实际上网消耗了 1GB 流量，系统只扣除你 0.5GB 配额，相当于五折优惠；反之，如果节点标有 `3.0x`，你下载 1GB 文件，系统会从你账户中扣除整整 3GB 流量。高倍率通常代表该节点租用了极其昂贵的高清内网专线或纯净住宅 IP，成本极高。新手看网页或文字查资料优先选常规 1.0x 节点即可，切忌在数倍率的节点上挂机下载大容量文件。

### 5. 为什么开启客户端后，国内的微信、QQ经常掉线，或者淘宝提示异地登录？
这通常是因为你的客户端模式被误设置成了“全局模式（Global）”。在全局模式下，包括微信在内的所有国内应用流量都会被强制导向位于香港或美国的境外服务器再折返回来。这不仅会导致通信网络延迟骤然升高，微信服务器更会检测到你的账号在极短时间内从真实物理省份瞬间跳跃到了海外数据中心，从而触发系统的反盗号风控报警并弹出异地登录提示。检查客户端界面，将分流模式由“全局”切换回默认推荐的“规则（Rule）”模式，即可从根源上彻底解决这一烦恼。

### 6. 苹果手机怎么下载 Shadowrocket 小火箭？国区 App Store 为什么搜不到？
由于中国大陆区 App Store 的合规监管要求，所有网络代理类工具均无法在国区应用商店上架展示。在国区商店中搜索出来的全部是同名的仿冒钓鱼软件。要获取官方正版小火箭，必须先拥有一个海外地区（如美国、中国香港）的 Apple ID 账号。在 App Store 内部退出当前国区账号，登录外区账号后搜索 `Shadowrocket`（认准开发者为 Pan Gu，原价 2.99 美元），下载安装完毕后再切回原本的国区主账号，即可终身正常使用。

### 7. 为什么客户端测试延迟都是几百毫秒，但看视频一点都不卡？
客户端中显示的延迟数值（通常在 30ms 至 200ms 之间）代表你的设备向该节点服务器发送一个微小数据包并收到回包所消耗的**往返时间（RTT）**。延迟数值主要决定了你点击链接后网页首屏响应的快慢以及打网络游戏时的跟手度；而在线观看 4K 高清视频是否顺畅，核心取决于该节点线路能为你提供的**瞬时下行带宽吞吐量**（例如每秒能下载多少兆数据）。只要带宽充足且专线丢包率低，即便延迟有 150ms，视频缓冲进度条依然能够瞬间拉满，因此无需对百毫秒的延迟数据产生过度焦虑。

### 8. 订阅链接过期了或者流量用完了，客户端会自动扣我银行卡的钱吗？
绝对不会。绝大部分正规商业机场采用的都是“预付费充值码”模式，结算通常通过国内第三方免签聚合收银台或数字代币完成，没有任何机场有技术权限直接绑定你的个人银行卡或开通自动扣款代扣协议。当你的月度套餐到期或者可用高速流量耗尽时，节点只会静默断开停止连接，完全不需要担心会产生任何隐藏扣费或意外账单。如果下个月仍需使用，只需手动登录机场官网购买新套餐即可。

### 9. 什么是 TUN 虚拟网卡模式？新手到底要不要开启它？
常规的系统代理只能管辖 Chrome、Edge 浏览器等遵循系统 HTTP 规范的标准应用；而某些特定的桌面游戏、代码终端（Git / CMD）或老旧邮件软件不会走系统代理。开启 TUN 模式好比在你的操作系统内部额外插上了一张虚拟网卡，它能在网络底层接管整台设备进出的所有流量，实现全系统级的无死角代理。对于纯粹只需要刷网页、查资料、看视频的新手，保持默认的普通系统代理即可；只有当你遇到某些特定软件无论如何打不开网络时，再前往设置中开启 TUN 模式。

### 10. 为什么有些节点名字叫“IEPL 专线”，有些叫“BGP 中转”？它们有何区别？
区别在于跨境时是否经过公网海关防火墙。“IEPL 专线”是通过物理光纤拉设的端对端独立内网通道，网络数据全程在海关边境地下的物理专用光缆中穿行，完全不经过公网 GFW 审查，因此在任何特殊敏感时期均能保持 0 丢包与绝对的稳定；而“BGP 中转”则是先把流量送到国内各省的高速机房，再由该机房通过公网隧道转发至境外，虽优于普通直连，但在公网国际出口出现大面积拥堵时仍可能出现轻微丢包，其优势是价格更加亲民。

### 11. 使用公共免费节点查资料到底安不安全？会不会被盗号？
对于通过正规 HTTPS 协议加密的现代网络服务（如登录 Google 账户或访问银行网站），通信内容在你的浏览器与目标服务商之间全程具备端对端高强度加密，哪怕通过免费恶意节点传输，节点运营者也无法解密你的银行卡密码与明文聊天记录。但是，不良免费节点的最大风险在于**真实访问域名暴露、流量特征监听以及中间人重定向劫持**。黑客可以记录你每天访问了哪些网站，甚至在未加密的普通网页中注入广告脚本。因此，公共免费节点仅适合临时救急查阅资料，严禁在免费节点环境下进行任何金融交易或登录重要私密账号。

### 12. 换了新电脑或者新手机，需要重新花钱买一份机场套餐吗？
完全不需要。你所购买的机场套餐是与你的个人账号深度绑定的。只要你的新设备上下载并安装了合规客户端，并在新客户端中导入同一个订阅链接，新设备即可立即享用相同的节点与流量配额。唯一需要注意的是该套餐所允许的**同时在线设备数量上限（通常限制为 2 到 5 台）**。只要不同设备在同一时刻发起的并发连接没有超出套餐规定阈值，你可以在个人名下的笔记本、台式机、手机与平板电脑上随意无缝漫游使用。
