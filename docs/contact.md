# 联系我们与官方反馈通道

感谢您对飞机场（feijichang.homes）的关注与支持！为了能够高效处理各类事务，我们为不同诉求设立了专属联络途径：

## 1. 跑路失联与风险情报紧急提报 🚨

如果您所使用的机场近期出现以下任何异常，欢迎第一时间向我们提报实测证据：
- 官网主域名无法访问且备用域名全线失效超过 48 小时；
- Telegram 官方群组开启全员永久禁言或管理员退群；
- 客服工单系统长周期无人应答，节点全量超时（Timeout）；
- 出现突发性的超大额折价预售充值，存在资金盘跑路嫌疑。

**情报提报专用邮箱**：`intel@feijichang.homes`  
*(请在邮件中附带该机场名称、订阅官网、故障截图及提报简要说明，我们的分析团队核实后将同步更新至全网[跑路预警黑名单](/resources/warning/))*
