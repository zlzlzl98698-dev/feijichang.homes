# 2026 Clash 使用教程从入门到精通 模式分流、自定义规则、TUN网卡与终端代理调优大典

对于初次步入跨国网络加速生态的用户而言，Clash 客户端绝不仅仅是一个简单的“翻墙开关”，而是一套高度精密、基于规则驱动的本地分流路由器。面对软件界面中林林总总的“Rule 规则模式”、“Global 全局模式”、“TUN 虚拟网卡”、“DNS 劫持”以及“策略组（Proxy Groups）”，很多用户往往因为误开全局模式导致国内网银风控冻结，或者因为规则配置不当导致微信图片无法加载、终端开发环境下载依赖超时。

掌握一套符合现代网络工程规范的 Clash 使用方法，不仅能让跨国学术检索、外贸商务、4K 影音观影与外服网游联机快如闪电，更能确保境内流量毫秒级直连本地宽带，彻底避免昂贵节点流量的浪费。本篇深度实操手册将从零基础入门开始，循序渐进地带您穿透底层工作机理，掌握自定义规则编写、TUN 模式全量加速以及多端联动的核心技艺。

## 章节一 从零入门到精通的三步标准工程闭环

对于新手用户，配置 Clash 绝不能胡乱点击。请严格执行以下经过万名用户实测验证的“三步标准闭环”：

### 1. 第一步：正版客户端安装与初始化运行
以当前桌面生态的绝对王者 **Clash Verge Rev** 为例：
1. 从官方 GitHub Releases 仓库或受信任的开源镜像下载 `Clash.Verge_x64-setup.exe`。
2. 运行安装程序完成安装。首次启动后，界面会自动适配简体中文。
3. 进入客户端“设置” -> “内核设置”，确认当前生效的内核为 **`Mihomo`**（这是确保后续所有现代协议与分流特性能完整发挥的基础）。
4. 在设置主界面勾选“**开机自启（Auto Launch）**”与“**静默启动（Silent Start）**”，让软件随 Windows 启动并在系统托盘常驻，彻底免去每次开机手动打开的麻烦。

### 2. 第二步：机场订阅导入与生效激活
1. 登录您所采购的正规机场后台，复制专属的 Clash 订阅直链（格式为 `https://...`）。
2. 在 Clash Verge Rev 界面左侧点击“**订阅（Profiles）**”菜单。
3. 将链接粘贴至顶部地址栏，点击“**保存并导入**”。待进度条转完后，界面中央会生成一张全新的配置卡片。
4. **关键一步**：在订阅卡片上点击鼠标右键，选择“**使用（Use）**”（或直接在卡片左侧点击单选框使其亮起蓝色激活标记）。此时内核会自动热重载配置文件。

### 3. 第三步：选择节点、锁定模式与开启系统代理
1. 点击左侧“**代理（Proxies）**”菜单，您会看到服务商预设的各种策略组（如“节点选择”、“自动选择”等）。
2. 点击右上角的闪电测速图标，发起一次全量延迟检测。在列表中挑选一条显示为绿色毫秒数值的香港、日本或新加坡专线节点。
3. 在左上角的代理模式中，**务必确认勾选为“Rule（规则模式）”**。
4. 点击左侧“设置”菜单，打开“**系统代理（System Proxy）**”开关。
5. 打开浏览器访问 `www.google.com` 与 `www.baidu.com`，若外网秒开、国内百度也能秒开且 IP 归属地依旧显示为您原本的本地城市，恭喜您，完整的工程闭环配置成功！

### 4. 服务模式（Service Mode）安装与开机守护机制
为了避免每次开启电脑或启动 TUN 虚拟网卡时反复弹窗请求 Windows 管理员权限，建议在首次装机时完成“服务模式”注册：
1. 打开客户端“设置” -> “服务模式（Service Mode）”，点击右侧的“安装（Install）”。
2. 在弹出的系统 UAC 提示窗口中点击“是”，系统会自动向 Windows 服务注册表注入一个名为 `clash-verge-service` 的后台常驻服务。
3. 注册完成后，旁边的图标会显示绿色对勾。此时即使是以普通受限用户身份登录电脑，客户端也具备了无感安装网卡驱动与修改底层路由表的特权，开机自启真正做到了静默无感。

### 5. 系统托盘常用快捷操作与无界面快速切线
在日常高频办公中，完全没有必要每次都打开臃肿的软件主窗口进行操作：
- **单击任务栏小托盘图标**：在弹出的迷你悬浮窗中，可以秒级切换当前的代理模式（Rule / Global / Direct），并快速开启或关闭系统代理开关。
- **右键小托盘图标**：直接呼出策略组快捷菜单，在不中断当前全屏游戏或视频播放的前提下，单手一键切换当前选中的节点线路。
- **配置快捷键（Hotkeys）**：在高级设置中，可以为“切换系统代理”绑定全局热键（如 `Ctrl + Shift + P`），遇到突发断网或本地局域网调试时，盲操一秒即可关闭代理，极具极客操控感。

## 章节二 四大运行模式工作原理与场景选型

Clash 的核心精髓在于“智能分流”。掌握其四大模式背后的网络流动逻辑，是避免日常故障的关键。

### 1. Rule（规则模式）：绝对的日常统治模式
在 **Rule（规则模式）** 下，本地内核充当了一个极速分流哨兵。
- **底层流转逻辑**：当您的电脑发起一个网络连接请求时（例如向目标发送一个 TCP SYN 报文），内核会按顺序比对内置的上万条分流规则：
  - 如果目标属于百度、微信、腾讯视频、国内网银等预设的 `DIRECT` 规则集，内核在 0.1 毫秒内放行，让数据直接通过您原本的电信/联通宽带直连出海，速度最快且完全不消耗机场流量。
  - 如果目标属于 Google、YouTube、GitHub、Twitter 等预设的 `PROXY` 规则集，内核将数据包封装进高强度的加密隧道，通过您在策略组中选定的优质境外专线节点转发。
  - 如果目标属于国内已知的垃圾广告域名，规则会将其直接指向 `REJECT`，在本地直接丢弃报文，实现网页级原生去广告。
- **结论**：在 99.9% 的日常生活中，请坚决将模式锁定在 Rule 模式上。

### 2. Global（全局模式）：暗藏杀机的极端模式
很多新手误以为“全局模式就是加速得更彻底”，这是极具破坏性的认知误区。
- **底层流转逻辑**：在 Global 模式下，所有的分流规则全部被强制无视。无论您访问的是海外的 Google，还是国内的百度、微信支付、淘宝网，整台电脑发起的所有流量一律无差别硬塞进您当前选中的那一条境外节点转发。
- **致命副作用**：
  1. **国内服务大面积瘫痪**：访问国内 App 时，由于流量需要先绕道香港甚至美西机房再折返国内，访问延迟暴涨数倍，网页打开极度缓慢甚至超时。
  2. **账号异地风控封禁**：国内银行 App、微信支付、各类政务平台检测到您的登录 IP 瞬间变成了境外数据中心 IP，会立即触发反洗钱与异地盗号风控，强制冻结交易并要求人脸识别。
  3. **流量疯狂透支浪费**：在腾讯视频、Bilibili 看高清视频时，所有的千兆大流量都在悄悄扣除您宝贵的机场外网套餐额度。
- **唯一合法使用场景**：仅用于新买了一个冷门海外 VPS 节点、需要快速验证该节点的单一连通性；或者在进行特定外服网游联机排障时临时开启两分钟测试。

### 3. Direct（直连模式）与 Script（脚本模式）
- **Direct（直连模式）**：完全绕过代理内核。本机所有的网络请求全部直接连接互联网，相当于完全没开 Clash。主要用于当网络出现异常时，快速对照排查是本地宽带断网还是代理节点故障。
- **Script（脚本模式）**：通过在本地执行图灵完备的 JavaScript 代码函数，根据目标端口、发起进程甚至系统时间动态决定流量流向，专为极客高级玩家打造。

### 4. 模式切换后的连接套接字清理与浏览器连接池重置
很多用户在排障时经常遇到这种困惑：“我刚刚把模式从全局切换回了规则模式，为什么打开国内网站依然很慢、或者查 IP 依然显示在香港？”
这是由于现代操作系统与 Chromium 内核浏览器的 **TCP 连接池保活机制（Keep-Alive）** 导致的：
- 当您在全局模式下打开过某个网站时，浏览器与远端服务器已经建立了一条持续保活的长连接，并将其缓存在本地 Socket 连接池中。
- 当您在客户端中将模式切换为 Rule 规则分流时，虽然新发起的请求会按新规则分流，但浏览器中尚未关闭的旧连接依然会沿着原本的旧长连接持续发送数据。
- **极速彻底重置方案**：
  1. 在浏览器地址栏中输入 `chrome://net-internals/#sockets`（Edge 输入 `edge://net-internals/#sockets`），点击界面上的“**Flush socket pools（刷新套接字池）**”按钮，强制关闭所有活跃连接。
  2. 在客户端“连接（Connections）”面板中，点击右上角的“**关闭所有连接（Close All）**”红色按钮，清空内核的活跃会话表。完成这两步后，新的规则模式便会以 100% 的精度即刻全面生效。

## 章节三 策略组（Proxy-Groups）机制与流媒体/AI 专属调度

很多初学者打开“代理”窗口时，会被密密麻麻的分组搞得眼花缭乱。理解策略组的类型，能让您的节点调度事半功倍。

### 1. 常见策略组的四大类型解密
- **`select`（手动选择型）**：最常见的策略组。用户必须在图形界面上手动点击勾选某一个具体的节点，选定后流量便死死绑定在该节点上，直到用户下一次手动切换。适合外贸电商或 ChatGPT 这种对 IP 变动极其敏感的场景。
- **`url-test`（自动测速型）**：组内包含多个节点。内核每隔一段时间（如 300 秒）会自动向测试网址（如 `https://www.gstatic.com/generate_204`）发送探测包，并自动将流量调度给延迟最低的节点。
  - **重要参数调优**：务必确认该策略组配置了合理的 `tolerance（容差）`（建议 50ms）。如果当前节点延迟是 40ms，另一个节点偶尔跳到 35ms，小于 50ms 的微小波动不会触发换线，避免了在线视频或游戏频繁跳线引发的卡顿。
- **`fallback`（容灾回退型）**：高可用首选。按照预设的列表顺序，永远优先使用排在第一位的节点；只有当第一位节点彻底断连挂掉时，才会毫秒级自动切换到第二位备用节点；一旦第一位节点恢复健康，流量自动切回。
- **`load-balance`（负载均衡型）**：将用户的并发 TCP 连接轮询或者按哈希分散分发给不同的节点并发传输。虽然能显著提升多线程下载大文件的总带宽，但缺点是极易导致同一个网页的不同请求来自不同国家的 IP，导致网页频繁弹窗验证码甚至掉登录态。

### 2. 流媒体解锁与前沿 AI 服务的专属节点绑定实战
以日常使用 ChatGPT、Claude 与 Netflix 为例，最科学的做法是**专线专用**：
1. 在策略组中找到服务商预置的“**OpenAI / ChatGPT 专属策略组**”。
2. 将该策略组单独手动绑定至一条纯净度极高的美国原生专线（如“美国 01 | 原生 IP”）。
3. 找到“**国外媒体（Streaming）专属策略组**”，将其单独绑定至一条经过实测解锁了 Netflix 完整版权库的新加坡或香港高速节点。
4. 找到“**默认代理（Proxy）**”策略组，将其设置为由“自动测速（URL-Test）”智能托管。
通过这一套优雅的组合拳：当您日常刷网页时，享受全自动最低延迟；当您打开 ChatGPT 时，流量悄悄走美国原生 IP，彻底告别“Access Denied”；当您打开 Netflix 追剧时，享受 4K 极速杜比视界，互不干扰，井井有条。

### 3. Load-Balance 负载均衡算法深度技术对比与 IP 漂移防范
部分拥有大量冗余大带宽节点的用户喜欢配置 `type: load-balance` 策略组。理解其内部调度算法至关重要：
- **`round-robin`（纯轮询算法）**：将新发起的连接按顺序依次分配给列表中的节点 A、B、C。虽然总带宽利用率最高，但在浏览带有 Session 鉴权的复杂网页时，前一个静态图片请求来自香港 IP，后一个表单提交来自日本 IP，极易触发网站的反爬虫验证码拦截。
- **`consistent-hashing`（一致性哈希算法）**：根据用户请求的目标域名或目标 IP 计算哈希值，确保同一个目标网站的所有请求始终固化分配给某单一节点。既享受了多节点分担并发压力的红利，又完美规避了 IP 漂移导致的频繁掉登录态。

### 4. 嵌套策略组（Nested Proxy Groups）级联路由设计
在构建高阶分流拓扑时，可以将策略组作为子元素嵌套入另一个策略组中。例如：
创建一个名为“顶级出口总调度”的手动选择组，其子候选池不直接填写真实节点，而是填入“香港 IEPL 专线组”、“美西大带宽组”、“自动测速容灾组”。通过这种分层解耦的级联架构，您可以在主界面仅凭一个卡片，瞬间掌控整台电脑全量流量的跨境战略流向。

## 章节四 自定义分流规则（Rules）语法精讲与实战注入

许多用户常遇到这种烦恼：“我的公司内网有个境外分支机构域名，或者某个特殊的学术数据库，机场自带的规则把它误判成了直连打不开，怎么手动添加规则让它强制走代理？”

### 1. 常见的核心规则类型语法解析
在 Clash 的分流世界中，每一行规则由逗号分隔为三个或四个部分：`规则类型,匹配目标,目标策略组[,no-resolve]`。以下为最常用的六大规则类型：

1. **`DOMAIN-SUFFIX`（域名后缀匹配）**：最常用规则。只要目标域名的末尾包含指定字符串即命中。
   ```text
   DOMAIN-SUFFIX,google.com,PROXY
   DOMAIN-SUFFIX,github.com,PROXY
   DOMAIN-SUFFIX,taobao.com,DIRECT
   ```
2. **`DOMAIN-KEYWORD`（域名关键字匹配）**：只要域名中包含某一段字符即命中，适合匹配多变泛域名。
   ```text
   DOMAIN-KEYWORD,openai,OpenAI-Group
   DOMAIN-KEYWORD,claude,OpenAI-Group
   ```
3. **`IP-CIDR`（IP 网段无类域间路由匹配）**：根据目标服务器的真实 IP 网段进行匹配。
   ```text
   IP-CIDR,192.168.0.0/16,DIRECT,no-resolve
   IP-CIDR,10.0.0.0/8,DIRECT,no-resolve
   ```
4. **`GEOIP`（地理位置国家代码匹配）**：根据本地离线 IP 数据库自动识别目标服务器所属国家。
   ```text
   GEOIP,CN,DIRECT
   ```
5. **`PROCESS-NAME`（操作系统进程名匹配）**：根据发起网络请求的本地程序名精准拦截。
   ```text
   PROCESS-NAME,git.exe,PROXY
   PROCESS-NAME,Telegram.exe,PROXY
   PROCESS-NAME,WeChat.exe,DIRECT
   ```
6. **`MATCH`（最终兜底匹配）**：必须且只能放在所有规则的最底端。当以上所有规则均未命中时，执行最后的默认动作。
   ```text
   MATCH,PROXY
   ```

### 2. 避免规则被覆盖的 Merge 扩展注入实战
千万不要直接打开本地下载的订阅文件进行手动修改！因为一旦机场订阅发生自动更新，您的所有手写修改都会被瞬间冲刷得荡然无存。

**终极标准解决方案：在扩展配置（Merge）中注入 Prepend Rules**：
打开 Clash Verge Rev，点击左侧“订阅” -> 右上角“扩展配置” -> “添加扩展”，输入以下标准化代码：

```yaml
# 自定义分流规则注入实战模板
prepend-rules:
  # 1. 强制让本地公司私有云与学术内网绝对走直连
  - DOMAIN-SUFFIX,oa.company.com,DIRECT
  - DOMAIN-SUFFIX,internal.corp,DIRECT
  
  # 2. 强制修复误判走代理的国内常用开发者源
  - DOMAIN-SUFFIX,npmmirror.com,DIRECT
  - DOMAIN-SUFFIX,gitee.com,DIRECT

  # 3. 强制让特定学术文献数据库走香港低延迟专线
  - DOMAIN-SUFFIX,sciencedirect.com,PROXY
  - DOMAIN-SUFFIX,ieee.org,PROXY

  # 4. 强制广告拦截丢弃
  - DOMAIN-KEYWORD,adservice,REJECT
  - DOMAIN-SUFFIX,doubleclick.net,REJECT
```
点击保存并应用。由于采用了 `prepend-rules`，这些规则会被客户端永久固定注入在机场规则的最顶端。无论机场订阅如何天天自动刷新，您的私有自定义规则坚如磐石，终生有效。

### 3. 动态外部规则集（Rule-Providers）挂载与自动同步
如果您需要维护成千上万条广告拦截、流媒体解锁或国内应用绕过规则，逐行手写极其低效。推荐直接挂载全球维护度最高的开源外部规则集（如 Loyalsoldier/clash-rules）：

```yaml
# 外部动态规则集挂载实战
rule-providers:
  reject:
    type: http
    behavior: domain
    url: "https://raw.githubusercontent.com/Loyalsoldier/clash-rules/release/reject.txt"
    path: ./ruleset/reject.yaml
    interval: 86400

  gfw:
    type: http
    behavior: domain
    url: "https://raw.githubusercontent.com/Loyalsoldier/clash-rules/release/gfw.txt"
    path: ./ruleset/gfw.yaml
    interval: 86400

prepend-rules:
  - RULE-SET,reject,REJECT
  - RULE-SET,gfw,PROXY
```
内核会在后台每隔 24 小时自动更新规则库，且查询在内存基数树中以 $O(k)$ 极速完成，丝毫不拖慢网络吞吐。

### 4. 规则匹配优先级天梯法则与穿透调试排错
Clash 分流引擎最核心的运行铁律是：**从上至下严格按顺序比对，一旦命中任何一条规则立即终止后续检索（First-Match-Win）**！
新手常犯的致命错误是将泛匹配规则放在了顶端：
- 如果您在最上方写了 `- GEOIP,CN,DIRECT`，那么当您访问一个架设在国内 CDN 上的被墙海外网站时，系统在第一行直接命中国内 IP 并放行直连，导致后续的代理规则完全沦为摆设。
- **标准的黄金天梯优先级顺序**：
  1. `REJECT` 恶意广告与追踪域名（最优先拦截丢弃）。
  2. 本地局域网与企业内网直连（`DIRECT`）。
  3. 精确域名与关键字代理规则（`OpenAI / Google / GitHub`）。
  4. 外部大规则集（`RULE-SET,gfw,PROXY`）。
  5. 地理位置与运营商大类分流（`GEOIP,CN,DIRECT`）。
  6. 兜底规则（`MATCH,PROXY` 或 `MATCH,DIRECT` 必须放在最后一行）。

## 章节五 高级功能实战：局域网共享与跨平台终端提速

Clash 的强大不仅限于单机，它更能将加速能力辐射至整个局域网中的各种智能终端。

### 1. 开启 Allow LAN 局域网共享：给 Switch 与手机一键加速
很多用户拥有 Nintendo Switch 游戏机、PS5 主机、或者未安装任何代理客户端的备用手机。只需让电脑充当代理跳板，即可无感共享极速网络：
1. 打开电脑端 Clash Verge Rev，进入“设置”，勾选“**允许局域网连接（Allow LAN）**”。
2. 查看当前客户端监听的混合端口（默认通常为 **`7897`** 或 **`7890`**）。
3. 在电脑键盘按下 `Win + R` 输入 `cmd` 打开终端，输入 `ipconfig`，找到电脑在当前家庭 Wi-Fi 下分配的内网 IPv4 地址（例如 `192.168.1.188`）。
4. 拿起 Switch 游戏机或手机，进入系统设置 -> Wi-Fi -> 点击当前连接的家庭 Wi-Fi -> 修改设置：
   - 将“代理服务器”从关闭修改为“手动（Manual）”。
   - “服务器/主机名”填入您电脑的内网 IP：`192.168.1.188`。
   - “端口”填入：`7897`。
5. 保存并连接。此时游戏机上的任天堂 eShop 商店秒开，联机下载大型游戏直接拉满百兆宽带！

### 2. 跨国程序员必备：命令行终端环境变量极速注入
很多开发者抱怨：“我桌面开着 Clash，为什么在终端里执行 `git clone` 或 `pip install` 依然只有几 KB 的龟速甚至直接报超时错误？”
这是因为操作系统的注册表代理默认只管桌面 GUI 应用，终端命令行拥有独立的网络运行栈。解决此痛点有两种标准工程方案：

- **方案一：一劳永逸开启 TUN 模式**：
  在 Clash Verge Rev 设置中，安装服务模式并直接开启“TUN 模式”。此时终端中的所有底层 TCP/UDP 数据包直接在网卡驱动层被截获，无需在终端中敲入任何命令即可实现透明加速。
- **方案二：终端临时注入代理环境变量（即用即开）**：
  在 Windows PowerShell 终端中执行单行指令：
  ```powershell
  $env:HTTP_PROXY="http://127.0.0.1:7897"; $env:HTTPS_PROXY="http://127.0.0.1:7897"
  ```
  在 macOS / Linux 终端中执行：
  ```bash
  export http_proxy="http://127.0.0.1:7897"
  export https_proxy="http://127.0.0.1:7897"
  ```
  执行完毕后，终端环境瞬间接入高速通道，拉取境外依赖如丝般顺滑。

### 3. WSL2 子系统镜像网络模式代理穿透实操
Windows 开发者在使用 WSL2（Linux 子系统）时，由于 WSL2 原生采用 Hyper-V 内部虚拟交换机，其拥有独立的虚拟 IP，传统的 `127.0.0.1` 代理在子系统内无法访问。
在现代 Windows 11 环境下，最佳实践是开启 WSL 镜像网络模式（Mirrored Mode）：
在用户家目录 `C:\Users\您的用户名\` 下新建或编辑 `.wslconfig` 文件：
```ini
[wsl2]
networkingMode=mirrored
dnsTunneling=true
autoProxy=true
```
保存后在 PowerShell 执行 `wsl --shutdown` 重启子系统。此时 WSL2 与 Windows 宿主机完全共享网络堆栈与代理状态，子系统内的 `apt update`、`docker pull` 无需任何配置即可秒级畅享加速。

### 4. VS Code Remote-SSH 远程开发免超时配置
当需要使用 VS Code 连接位于海外云机房的 VPS 虚拟机进行开发时，频繁遭遇握手超时或掉线。可以在本地的 `~/.ssh/config` 配置文件中注入 ProxyCommand 穿透通道：
```ssh-config
Host my-foreign-vps
    HostName 1.2.3.4
    User root
    ProxyCommand connect -S 127.0.0.1:7897 %h %p
```
通过本地 SOCKS5 混合端口中继，VS Code 远程长连接稳如磐石，彻底消除敲击键盘时的卡顿感。

## 章节六 日常网络使用安全守则与性能自查规范

为了长期享受稳定、安全且低风控的网络加速服务，请将以下四条日常安全守则牢记于心：

### 1. 节点测速延迟的科学认知
在客户端界面中点击闪电测速跑出的毫秒数（例如 35ms），仅仅代表您的电脑与该海外机房入口服务器之间的单次网络握手响应时间。**它绝不等于下载大文件时的实际带宽上限**！
- 极低的延迟（如 20ms）代表该线路为优质的 IEPL/IPLC 企业级内网专线，适合外服打游戏与高频网页交互。
- 稍高但稳定的延迟（如 120ms 的美西专线）非常适合观看 4K/8K 极限高清视频与大容量备份下载。不要盲目迷信数字越小越好，晚高峰不丢包、不跳 ping 才是稳定的唯一金标准。

### 2. 严禁多个代理客户端同台混跑
许多用户电脑上既安装了 Clash，又安装了 v2rayN、Sing-box、甚至某些杀毒软件自带的网络保护工具。
当多个代理软件同时开启“系统代理”或尝试注入各自的虚拟网卡时，会引发剧烈的 Windows 注册表竞争与本地端口冲突（经典报错：`Address already in use: 7890`）。这会导致操作系统的路由网关发生撕裂，连正常的国内网页都无法打开。最佳实践：日常使用坚决只保留并运行一个经过良好配置的客户端，其余软件彻底退出后台进程。

### 3. WebRTC 穿透与 DNS 泄漏在线检测终极体检
配置完成后，建议每隔一段时间进行一次网络安全体检：
- 打开在线检测平台（如 BrowserLeaks 或 IPleak.net）。
- 观察检测结果中的 **WebRTC IPv4 / IPv6** 栏目：若显示出的 IP 为您真实的中国宽带 IP，代表 WebRTC 发生了旁路穿透泄露，需在浏览器中安装“WebRTC Control”扩展彻底禁用。
- 观察 **DNS Addresses** 栏目：若列表里出现了您所在省市的电信/联通 DNS 服务器地址，代表存在 DNS 泄漏，需在客户端开启 TUN 模式或配置境外加密 DNS 分流。

## 12道 Clash 使用高频疑难与深度解答 FAQ

针对用户在日常使用中提出频率最高、最容易踩坑的 12 大疑难问题，我们整理了系统详尽的工程解答：

### 1. 为什么开启 Clash 之后，部分国内软件（如微信、企业微信）收发图片和文件变得非常卡？
这是由于 DNS 调度污染导致的典型“绕路 CDN 综合征”。国内大型互联网公司（如腾讯、阿里巴巴、字节跳动）在全国各省市都部署了密集的边缘 CDN 节点。如果客户端的 DNS 策略配置不合理、或者分流规则中未能精确识别这些域名的内网属性，会导致国内软件在查询解析时被错误分配了位于香港或境外的 CDN 节点 IP，从而导致您向本地朋友发一张图片要绕道数千公里之外的海外机房。
解决方法极为明确：
1. 确认主界面的代理模式严格锁定在“Rule 规则模式”，绝对不可长期开启“Global 全局模式”。
2. 在 DNS 配置中将腾讯与国内主流域名集合（`geosite:cn` 与 `geosite:tencent`）显式指定使用国内公共 DNS（如 223.5.5.5 或 119.29.29.29）解析直连。
3. 在 Prepend Rules 扩展中，将 `*.qpic.cn`、`*.weixin.qq.com` 声明为 `DIRECT` 直连白名单，国内通讯即可瞬间满血恢复。

### 2. 为什么有时候节点列表里的所有节点测速都能跑通，但是浏览器却提示“无法访问此网站”？
当“节点能测出延迟但网页打不开”时，建议按照标准三步工程法排障：
1. **核验系统时钟准确性**：检查电脑任务栏右下角时间是否与真实北京时间完全同步。由于现代 TLS 握手依赖强时间戳加密，误差超过 60 秒会导致所有 HTTPS 加密证书校验失败并引发握手超时。
2. **核验系统代理开关状态**：确认客户端界面上的“系统代理”开关是否确实处于开启状态；很多时候由于第三方软件意外结束了进程，导致系统代理未被挂载。
3. **排查浏览器冲突扩展**：检查 Chrome 或 Edge 中是否安装了类似 SwitchyOmega、AdGuard 或其他网络代理插件，如果浏览器插件中配置了冲突的规则，会直接覆盖系统的网络代理设置。
4. **排除本地 DNS 回环锁死**：在 Windows 命令行执行 `ipconfig /flushdns` 刷新本地 DNS 解析缓存，清除先前直连失败时的负向解析记录。

### 3. Clash 界面中的“节点选择”、“自动选择”和“故障转移”有什么本质区别？
- **“节点选择（Select）”**：纯手动控制组。用户点选哪个节点，流量就固定走哪个节点，不会发生任何意料之外的自动漂移，适合办公与登入外服账号。
- **“自动选择（URL-Test）”**：智能竞速组。由内核定时向测试地址发起 Ping 测速，自动将连接送给当前测速毫秒数最低的节点。
- **“故障转移（Fallback）”**：高可用保活组。永远锁定主节点；主节点挂掉后自动无感顺延至备用节点，主节点复活后自动切回，适合关键业务长连接。

### 4. 电脑关机或重启后，发现网络彻底瘫痪连百度都打不开了，怎么快速恢复？
这是由于异常关机导致的“系统注册表残留锁定”故障。当电脑断电或强行关机时，Clash 来不及向系统注销代理端口，导致 Windows 网络设置中依然残留着指向本地 `127.0.0.1:7897` 的代理项，但此时本地程序尚未启动，因而所有网络全部中断。
极速自救四步法：
1. 按下键盘快捷键 `Win + R`，输入 `inetcpl.cpl` 打开 Internet 选项。
2. 切换到“连接”标签页，点击右下角“局域网设置”。
3. 将其中“代理服务器”区域的“为 LAN 使用代理服务器”复选框全部取消勾选。
4. 点击确定保存，网络即可瞬间彻底复原。为彻底避免此问题，建议在客户端设置中勾选“退出时自动清理系统代理”。

### 5. 为什么有时候打不开 ChatGPT 或 Claude，页面提示“Access Denied”？
这绝不是您的 Clash 软件有问题，而是因为您当前选中的物理节点的机房出口 IP 已经被 OpenAI 或 Anthropic 列入了高风险黑名单。前沿 AI 平台对数据中心机房 IP 实施了极其严厉的风控过滤。解决方法：在策略组中切换为具备住宅原生 IP 资质、或者经过服务商专门优化过 AI 鉴权流媒体解锁的节点，切忌使用万人共享的廉价免费公网节点。

### 6. TUN 模式和普通系统代理模式到底应该怎么选，平时需要一直开着 TUN 吗？
两者的选择取决于您的日常应用软件构成：
- **普通系统代理模式**：通过修改 Windows 注册表挂载本地 HTTP 代理。优点是零驱动依赖、系统资源开销极小，适合绝大多数仅使用浏览器查资料、看视频、用 Telegram 聊天的轻度办公用户。
- **TUN 虚拟网卡模式**：通过 Wintun 驱动在内核态虚拟出一张物理千兆网卡，全面接管整机所有 TCP 与 UDP 原始报文。对于跨国软件工程师（接管终端 Git、Docker 编译拉取）、重度外服电竞联机玩家（接管 Steam、Apex 全进程并开启 UDP 全锥型 NAT）以及安卓模拟器用户，**必须常驻开启 TUN 模式**。

### 7. 开启局域网共享（Allow LAN）后，家里的其他手机无法连接电脑的代理怎么办？
排查以下三大常见关卡：
1. **Windows 防火墙拦截**：Windows 操作系统默认会对普通程序的入站局域网连接进行静默拦截。打开 Windows Defender 防火墙，在“允许应用通过防火墙”列表中，将 Clash Verge 勾选允许在“专用网络”与“公用网络”中通信。
2. **Wi-Fi 开启了 AP 隔离**：某些家庭路由器或商用路由开启了“AP 隔离（Client Isolation）”功能，禁止连接同一个 Wi-Fi 的不同设备之间互相通信。在路由器管理后台关闭 AP 隔离即可。
3. **电脑内网 IP 发生变动**：电脑每次重新连接 Wi-Fi，路由器通过 DHCP 分配的内网 IP 可能会发生变化，在电脑终端输入 `ipconfig` 重新确认当前的最新内网 IP。

### 8. 为什么导入新订阅后，有些节点名字上带有“0.5x”、“2.0x”的倍率标识，这代表什么意思？
倍率标识代表该节点在消耗套餐流量时的**实际计费倍数**：
- **`1.0x`**：标准倍率。您实际下载了 1GB 的流量，在机场后台的月度套餐中扣除 1GB。
- **`0.5x` / `0.2x`**：廉价优惠倍率。通常为大流量专线或非高峰期备用线路，下载 1GB 流量只在后台扣除 0.5GB 或 0.2GB，非常适合用来跑大容量文件备份与下载。
- **`2.0x` / `3.0x`**：高成本精品倍率。通常为晚高峰绝对零丢包的顶级 IEPL 企业专线或极度稀缺的纯净住宅 IP，适合打游戏或在重大活动期间保障关键会议。

### 9. 怎么在 Clash 中彻底屏蔽网页上的各种烦人弹窗广告和跟踪探针？
在 Clash 中实现原生去广告，只需通过扩展配置引入社区维护成熟的去广告规则集（如 Anti-AD 或 Loyalsoldier 的 reject 规则）：
在 Merge 扩展中将这些规则集的动作全部指向 `REJECT`。当网页中嵌入的广告服务器域名被发起请求时，Clash 在本地直接熔断并返回拒绝连接，浏览器便不会加载任何广告脚本与图片，既极大净化了阅读界面，又节省了约 15% 的网页加载带宽。

### 10. Clash 能不能让指定的一个软件（例如某个浏览器）走代理，其余所有软件全部直连？
完全可以！Mihomo 内核原生支持基于进程名称与进程路径的精准白名单分流。您只需在 Prepend Rules 扩展中编写如下规则：
```yaml
prepend-rules:
  # 仅允许指定的浏览器与远程协作工具走代理策略组
  - PROCESS-NAME,chrome.exe,PROXY
  - PROCESS-NAME,Telegram.exe,PROXY
  # 其余所有软件无论访问什么网站全部强制绝对直连
  - MATCH,DIRECT
```
保存应用后，整台电脑上除了名单中指定的软件发起的请求会被送入专线节点外，其余所有软件（包括 Windows 系统更新、后台杀毒、本地联机软件等）全部强制走本地物理宽带直连，做到了绝对的隔离与极速。

### 11. 为什么有些网页（比如某些境外政务或网银）提示我“使用了代理禁止访问”？
这通常是因为浏览器通过 **WebRTC 协议**暴露了您真实的物理公网 IP。现代网页能够通过调用 JavaScript 中的 WebRTC 接口，向 STUN 服务器发起旁路 UDP 探测，从而绕过普通的 HTTP 代理探知物理网卡的本地 IP。
解决方法有两道工程屏障：
1. 在 Chrome 或 Edge 浏览器中安装名为“WebRTC Control”的扩展插件，将 WebRTC 的本地 IP 广播功能彻底禁用。
2. 直接开启 Clash 的 TUN 模式，并在规则中开启 `dns-hijack: ["any:53"]`，将整机所有的 UDP 旁路探测报文全部截获送入加密隧道。

### 12. 客户端界面里显示的“混合端口（Mixed Port）”到底是什么意思，跟普通的 HTTP/SOCKS 端口有什么区别？
在早期的网络代理工具中，HTTP 代理协议与 SOCKS5 代理协议必须监听在不同的端口上（例如 HTTP 走 7890，SOCKS 走 7891），用户在配置第三方软件时经常混淆弄错。Mihomo 内核实现了高度集成的 **混合端口（Mixed Port）**：单个端口能够自适应识别流入的数据流格式。无论前端发来的是标准的 HTTP/HTTPS 网页报文，还是原生的 SOCKS5 双向握手包，混合端口都能在毫秒内智能识别协议类型并完成解密转发，大幅简化了多设备的网络配置负担。同时支持在此端口上直接配置用户名与密码强认证机制，有效保障了在公共 Wi-Fi 或宿舍环境下开放局域网共享时的连接安全，彻底防止未授权蹭网。
